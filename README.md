# 分镜台

口播稿逐句分镜标注工具（macOS 桌面应用，基于 Electron）。

把逐字口播稿按句拆开，逐句标 **A roll / B roll**（B roll 分四个子类）、写批注，最后导出带批注的 MD、素材清单或 CSV，直接交给剪辑。

## 下载安装

按你的芯片选一个包（不确定就点  菜单 → 关于本机 看「芯片」：Apple M 系列选 arm64，Intel 选 x64）：

| 芯片 | 安装包（dmg） |
| --- | --- |
| Apple M 系列（M1/M2/M3/M4…） | [FenJingTai-mac-arm64.dmg](https://github.com/p56568833/fenjingtai/releases/latest/download/FenJingTai-mac-arm64.dmg) |
| Intel | [FenJingTai-mac-x64.dmg](https://github.com/p56568833/fenjingtai/releases/latest/download/FenJingTai-mac-x64.dmg) |

上面的链接永远指向最新版。也可以去 [Releases 页面](https://github.com/p56568833/fenjingtai/releases) 看历史版本；每个版本同时提供 `.zip`（解压即用，适合脚本下载）。

**首次打开**：应用没有苹果开发者签名，第一次打开会提示无法验证开发者。macOS 15（Sequoia）及以后：先双击一次，然后到「系统设置 → 隐私与安全性」底部点「仍要打开」，再确认一次（只需一次，之后正常双击启动）。macOS 13–14 也可以在应用图标上**右键 → 打开 → 再点打开**。

系统要求：macOS 13（Ventura）或更新版本。

数据全部存本机（`~/Library/Application Support/分镜台/数据/`），不联网上传任何内容。写盘时每隔 30 分钟顺带备份一份：最近 24 小时的全部保留，更早的每天留一份、保留 30 天。数据文件万一损坏，启动时会把坏文件改名保留，并自动用最近一份能读的备份恢复。

## 给 AI 助手 / 脚本

固定直链（永远最新版），curl 加 `-L` 跟随重定向即可：

```bash
# Apple Silicon
curl -L -o FenJingTai-mac-arm64.dmg https://github.com/p56568833/fenjingtai/releases/latest/download/FenJingTai-mac-arm64.dmg
# Intel
curl -L -o FenJingTai-mac-x64.dmg https://github.com/p56568833/fenjingtai/releases/latest/download/FenJingTai-mac-x64.dmg
```

dmg 挂载：`hdiutil attach FenJingTai-mac-arm64.dmg`，然后把 `分镜台.app` 拷到 `/Applications`。压缩包版本把上面 URL 里的 `.dmg` 换成 `.zip`。

## 从源码运行 / 打包

```bash
npm install
npm start          # 直接跑
npm test           # 全部自测（数据层 + 主进程 + 桌面交互，会起一个隐藏的 Electron 窗口）
npm run test:data  # 只跑不需要 Electron 的部分（GitHub Actions 每次 push 自动跑这个 + lint + 格式检查）
npm run lint       # ESLint 检查
npm run format     # Prettier 统一格式
npm run package    # 出 arm64 + x64 双架构安装包到输出所示的临时 .noindex 目录；上传后删除该目录（只打包 electron/、renderer/、package.json，代码打成 app.asar，自测代码不进安装包）
```

### 代码结构

渲染层按职责分四层，上层可以用下层，下层不知道上层（`npm run lint` 会检查）：

| 目录 | 放什么 | 规矩 |
| --- | --- | --- |
| `renderer/src/core/` | 纯数据规则：分句、镜头 / 共用画面、素材模型、标注类型、时间轴、字幕对齐、导出文本 | 不碰界面、不碰应用状态，node 里能直接测 |
| `renderer/src/app/` | 应用状态、存盘、撤销、所有改数据的操作 | 不碰界面；改完只广播事件、发提示 |
| `renderer/src/ui/` | 视图和交互：表格、原文、侧栏、弹窗、菜单 | 不直接调用功能模块，用 `commands.js` 里登记的命令 |
| `renderer/src/features/` | 独立功能：专注标注、字幕对齐、素材预览、口播播放、连播预览、类型编辑器、PDF 导出、视频审核 | 自己登记命令 |
| `renderer/src/platform/` | 原生能力（文件、对话框、存盘）的唯一出入口 | 不依赖业务代码 |
| `renderer/src/test/` | 桌面交互自测 | 不进安装包 |

## 功能

- 粘贴 / 导入口播稿（MD、TXT），自动按句拆分，支持章节标题
- 逐句或拖选批量标注 A roll / B roll（B roll 四个子类），快捷键 1/2/3/4/5
- 原文视图与表格视图一键切换（⌘T），浅色 / 深色主题（⌘L）
- 批注写备注，导出带批注 MD / 素材清单 MD / CSV / 项目 JSON
- 数据自动落盘 + 分层自动备份（24 小时内全留、之后每天一份留 30 天），可从备份恢复


## 1.1 工作流更新

- **长稿导航**：章节目录显示各章剩余未标句数；可跳到下一个未标注，按项目恢复上次处理的句子。自动跳转默认关闭，可自行勾选。
- **统一标注**：原文、表格顶部均为筛选；选区工具条负责标注。选连续多句可合为镜头组，共用类型、画面描述、素材与制作状态；原文不合并。
- **画面与素材**：支持链接、本地素材文件、图片预览和待找素材／待制作／已就绪状态。输入自动保存，可撤销；链接和路径会写入项目，本地文件不嵌入项目，请随交稿另行打包。
- **节奏与时长**：顶部色条按原文顺序和估算时长排列，点击定位；时长菜单可调整语速。它是按字数估算，不是录音对齐的精确时间码。
- **导入预览**：新文本默认导入为新项目。可选择更新当前稿件：仅继承完全一致且不重复句子的标注，其他句子标为待核对；更新或替换前自动保留原项目副本。
- **分句修复**：新导入支持句尾引号和连续标点；旧稿通过“修复分句”手动处理无标注、无备注的孤立标点，可撤销。
- **交稿检查**：定位未标注、缺画面描述、素材未就绪和改稿待核对。允许带缺项导出。素材清单按镜头组去重，CSV 和项目 JSON 包含制作信息；带批注 MD 附有可回读的元数据。
- **界面**：浅色分类标签、简化底栏，可拖动备注列表头左边缘调整列宽。

运行 `node scripts/production-test.mjs` 检查分句与数据逻辑，`npm test` 检查桌面工作流；后者使用独立临时数据，不改实际项目。开发预览可用 `npm start -- --preview`，同样使用临时示例数据。


### 1.1.1 多选入口

表格每句左侧都有复选框，逐个勾选后点击「合为镜头组」。也可点击「多选句子」进入连续点选模式，选好后点「完成多选」退出模式（保留选区）。原文视图打开多选模式后，点击每句话即可勾选或取消。镜头组须为同一章节内连续的两句或更多；不连续多选仍可批量标注。点击「取消选择」清空选区。

### 1.1.2 按需多选与共用画面

勾选框默认隐藏，点击「多选句子」显示，点击「完成多选」收起。选中同一章节内连续的两句或更多后，点击「共用一个画面」：原文仍逐句保留，共用画面描述、素材、类型和制作状态；可点击「取消共用」恢复独立编辑。原有镜头组数据自动兼容，无需重新设置。

### 1.1.3 共用画面可视化与素材卡片

表格用连续边框和句子范围标识共用画面，原文视图也将相关句子围在同一区块。画面备注列直接展示关联素材名称、本地图片缩略图，点击可查看详情；未关联素材时显示明确入口。已有素材但尚未确认的状态显示为「素材待确认」。原文批注改为 20px 红色文字与红色侧线，深色模式对应亮红色。

### 1.1.4
共用画面改为轻量连续标记，后续句子沿用首句素材。素材支持逐个移除关联和撤销；本地视频显示系统生成的缩略图，点击可用默认播放器打开。

### 1.1.5
共用画面恢复淡蓝底与完整外框。组内逐句保留原文和时长，类型、状态、描述与素材合并为一份并在整组垂直居中，去除重复提示和组内类型竖线。

### 1.1.6
恢复共用画面内的类型竖线，与外框保持间距；修复共享批注输入框左边框。原文共用批注仅在整组末尾显示一次，组内任一句均可编辑同一份批注。

## 1.2 素材与共用范围

- **视图分工**：原文视图专注读稿与规划（类型底色、章节、共用边框、红色批注），素材、状态、播放器都收进右侧「画面与素材」面板（选句后从标注卡「画面与素材…」或共用区标题进入）；表格视图专注落实画面与素材。切换视图自动保存正在编辑的内容，并保持当前句子定位。
- **拖拽添加素材**：从访达拖一个或多个文件到表格某句、共用画面区域或右侧素材面板；拖到组内任一句关联到整个画面。拖到哪高亮哪，重复文件自动去重，多文件一次可撤销；保留「添加素材」按钮。
- **应用内预览**：图片点击看大图（适应窗口 / 缩放）；视频应用内播放（播放暂停 / 进度 / 时间），不自动播放、关闭与切项目即释放；解码失败明确报原因并保留「用系统播放器打开」。缩略图失败分「无缩略图（可重试）/ 格式不支持 / 文件失联」三种状态。
- **视频片段**：记录这个画面使用视频的哪一段（入点 / 出点：当前播放位置或手输 00:12），可预览选定片段、清除恢复整段；范围存在「本次素材关联」上，同一视频不同画面各用各的；随项目保存、可撤销。
- **文件失联**：原文件被改名 / 移动 / 删除后显示「文件失联」，保留原文件名、原路径与片段设置；「重新定位文件」会说明项目内有几处引用并一起修好，时长不兼容的片段标记「待调整」（不静默改时间）；「移除关联」从不删除本地文件。
- **本项目素材**：添加素材时可从「本项目素材」按名称搜索、按缩略图 / 类型 / 使用次数（共用画面算一处）选择已添加过的文件，不复制本地文件。
- **共用画面范围调整**：共用区「···」= 将下一句加入这个画面 / 将最后一句移出这个画面 / 解除共用；组内句子「···」= 从这句开始使用另一个画面（拆成前后两组）。只能加入紧邻下一句，不跨章节、不吞并别的共用画面；有差异先展示差异与处理方式再执行；每次调整一步撤销。原文 / 表格两视图入口一致。


## 1.3 专注标注 · 剪映字幕对齐 · 重做

- **专注标注（⌘E）**：一次只看一句（共用画面算一个），大字居中、前后各留两句上下文。按 1–5 标完自动跳到下一句，R 重复上一个类型，Tab 写画面描述，⌘Z 撤销，Esc 退出并停在最后处理的那句。默认只看未标注的句子。
- **剪映字幕对齐**：录完口播后，在剪映专业版导出时勾选「字幕导出」、格式选 SRT，把 SRT 拖进窗口（或 ⇧⌘O）。先预览对上多少句、哪些句子低置信或没找到，确认后每句换成真实时间码。表格显示时间码，时长、节奏色条、素材清单和 CSV（多出开始 / 结束时间列）都改用真实时间。错字、断句不同、口误和临场删改都能处理；没录的句子按前后推算并标黄，交稿检查里会提示。改稿后可以在「时长」菜单里重新对齐或清除。
- **重做**：⇧⌘Z（或 ⌘Y）。撤销 / 重做后光标回到改动发生的那一句。编辑文字时 ⌘Z 撤销的是输入本身。
- **拖进窗口导入**：MD / TXT / Word（.docx）/ 项目 JSON / SRT 直接拖进窗口。Word 的标题样式会识别成章节，GBK 编码的旧 txt 也能读。想把 txt、md 当素材关联，拖到右侧「画面与素材」面板。
- **按键调整**：⌫ 只清除标注（两个视图一致），⌘⌫ 才删除句子。视频预览里空格播放、I / O 设入点出点、← → 前后 1 秒。所有弹窗都能用 Esc 关闭。
- **更顺手**：搜索等拼音上屏后才搜；长稿（上千句）标注和搜索明显更快；时长估算里英文按单词计；记住窗口大小和位置；⌘+ / ⌘− 缩放。
- **更稳**：数据文件损坏不会再被示例稿覆盖；分层自动备份；页面加了内容安全策略、禁止跳转外部页面；发布版不再接受调试参数；打包改成白名单，备份文件夹不会被打进安装包。


## 1.3.1 PDF 分镜脚本

导出菜单新增「PDF 分镜脚本」（⇧⌘E），支持横竖版 A4、封面概览、素材缩略图与链接（1.5 起不再有制作状态）。共用画面的句子合为同一个镜头，口播原文逐句保留。当前素材库的视频片段和剪映字幕时间会写入 PDF，本地素材只显示文件名。
删除句子后提示条的撤销按钮可以正常恢复。保留 1.3 的专注标注、字幕对齐和重做。


## 1.4 素材角色与出现位置

一个画面挂了好几张照片 / 视频时，不再看起来像要轮着放。每条素材多了两个可选设置：

- **角色**（三选一，在右侧「画面与素材」面板里点选）：
  - **主画面**：这段的底，可以是视频，也可以是推拉的照片。同一句同一时刻只有一个：把别的素材设成主画面时，原来在同一句上的主画面自动降为备选，提示里会说明。
  - **叠加**：盖在主画面上的东西，比如人物肖像小卡、文件特写、报纸标题。
  - **备选**：先存着不用。表格里收成一个「备选 N 个」入口，素材清单和 PDF 里不出现（清单只报个数）。
- **出现位置**（只有共用画面才有）：「出现在 第 84 句 到 第 85 句」，默认整段。前后两段各用一个主画面也可以，只要位置不重叠。

其他细节：

- **默认值**：给空画面添加素材时，第一个默认是主画面，其余默认是备选。
- **旧项目**：已有的素材显示为「未分配」，导出照旧。面板里有一键整理（第一个当主画面，其余放备选），可以撤销。
- **换成视频时**：把视频设成主画面，原来的照片会自动让位成备选。要叠在视频上的照片，改成「叠加」就行。
- **共用画面调整**：合并画面时，原来只在某句上的素材仍只在那句出现。插句、拆句、并句时，位置跟着句子走。解除共用、移出或拆分后，每句只留下原本在这句出现的素材。
- **交稿检查**：开始用角色后会提醒「未指定主画面」或「部分句子没有主画面」。没用角色的旧项目不新增提醒。
- **导出**：素材清单、CSV 和 PDF 写上角色和出现位置，CSV 逐句只列这句实际出现的素材。带批注 MD 和项目 JSON 完整保存角色与位置，可以回读。

## 1.5 视频审核 · 去掉制作状态

让 Claude 找视频素材时，它不再给你一堆链接让你一个个点开，也不往「下载」里塞整部视频。流程是：

1. Claude 按画面找好候选视频，写成一份**候选清单**（`.json`，格式见下），放在你电脑上的任意文件夹。
2. 把清单拖进分镜台窗口，或点「导入」选它。清单会挂到**当前项目**，不新建项目，并自动打开「视频审核」窗口。工具栏上会多一个「视频审核 · N 待审」按钮；右侧画面面板里也有「视频候选 N 个 · 去审核」入口。
3. 每个候选显示：编号、标题、建议片段（几分几秒到几分几秒）、版权、推荐理由、对应的口播原文，以及从建议片段里均匀截的 **6 张截图**。拿不准再点「播放这段」（点一下就开始加载并播放，缓冲时按钮显示「载入中…」），只播建议的那几秒。播放器只显示这几秒的进度（如 0:04 / 0:13），画面上叠口播字幕；片段第 0 秒对齐到它配的那句开头，进度条上标出句子分界，画面比口播短时会提示。导入了口播音频时默认同时播口播声音（可关，记住选择），播到出点自动回到入点。这一步不保存任何文件。
4. 点 **通过 / 不要 / 换一个**，可以写一句意见（比如「要近景」「换成冷藏车外景」）。
   - **通过**：视频挂到这个画面上，角色是**主画面**，片段入出点就是建议的那几秒；原来的主画面照片自动让位成备选。画面描述末尾追加一行来源：`视频：标题｜01:41–01:50｜公有领域｜原片页面链接`。同一画面再通过的视频也直接当主画面（几个主画面平分那段时间），已通过的不会被顶掉；不想要哪个当主画面，在面板里点成「备选」。
   - 画面描述太长时，表格里只显示前 4 行、末尾省略号；点进去编辑就展开全文，右侧面板也能看全文。
   - 再点一次「通过」就是撤回：素材拿掉，画面描述那一行删掉。所有审核操作都能 ⌘Z 撤销。
   - 刚审过的卡片先留在原处，切换筛选（待审 / 已通过 / 全部）后才收起。「清除『不要』的」把标成不要的候选删掉。
5. 审核结果（通过 / 不要 / 换一个 + 意见 + 保存位置）**自动写回候选清单文件**，每个候选多一个 `review` 字段。Claude 读这个文件就知道哪些要换、你想要什么。
6. **保存已通过的片段**：顶部按钮一次保存全部尚未保存的已通过片段。每段只截取建议的入点到出点，存成 mp4（文件名形如 `第125-127句_标题_1m41s-1m50s.mp4`，重名自动加 (2)），素材自动换成这个本地文件。第一次保存会问存到哪个文件夹，之后可在窗口里「更换保存位置」。顶部按钮显示当前片段序号和截取进度。
7. **下载完整原片**：每张卡片右下角的小按钮，要再确认一次才会下载整部视频（可能几百 MB）。不点就不会下。

**需要 ffmpeg**：批量保存片段用本机的 ffmpeg 截取。没装的话会弹窗提示；在「终端」里运行 `brew install ffmpeg` 装好即可（会在 /opt/homebrew/bin、/usr/local/bin、/usr/bin 里找，也可以用环境变量 `FJT_FFMPEG` 指定）。截图、播放、通过、写回都不需要 ffmpeg。

**内容安全策略放开**：为了能直接播放和截图网上的视频，`renderer/index.html` 的 CSP 允许从任意 http / https 地址读取图片、视频和网络请求（`img-src` / `media-src` / `connect-src`）。脚本仍然只能来自应用本身。

**去掉制作状态**：「待找素材 / 待制作 / 已就绪」整个去掉了：面板里的下拉框、表格角标、交稿检查的「素材未就绪」、素材清单 / CSV / PDF 里的状态列都不再出现。顶部统计改成「已挂素材 N / B roll 镜头数」（挂了主画面、叠加或未分配素材的画面，不算备选）。旧项目里的状态字段保留在数据里，不影响打开。

### 候选清单格式（给 Claude / 脚本）

```json
{
  "type": "fenjingtai-candidates",
  "version": 1,
  "project": "第四期礼来稿子2 · 推荐分镜",
  "shots": [
    {
      "lines": "101-103",
      "label": "屠宰场与胰腺来源",
      "cands": [
        {
          "key": "A1",
          "title": "福特教育片 1922 · 肉类加工",
          "url": "https://archive.org/download/fc-fc-485/fc-fc-485.mp4",
          "page": "https://archive.org/details/fc-fc-485",
          "in": 101,
          "out": 110,
          "license": "公有领域",
          "why": "流水线上的牛肉，和口播的屠宰场对得上"
        }
      ]
    }
  ]
}
```

- `lines`：画面对应的句号，写 `"101-103"`、`"101–103"` 或单个 `101` 都行；按**起始句号**找到它所在的画面（共用画面挂整组）。对不上句子的候选会跳过并提示。
- `url`：能直接播放的视频文件地址（mp4 / webm 等），不能是网页地址；网页放在 `page`。
- `for`（可选）：这段配画面里的哪几句，如 `"200"` 或 `"200-201"`。审核卡片上显示「配：第 200 句『…』」，整段口播里高亮这句；通过后素材只在这几句出现。没写就是整段。已通过的候选在清单里补写 `for` 后再导入，出现范围会跟着改。
- `in` / `out`：秒数，或 `"1:41"` 这种写法。`key` 在同一个 `lines` 里唯一，写回时按 `lines + key` 对应。
- 同一份清单再导入只更新不重复；链接或时间改了的候选会回到待审。
- 写回后每个候选多出 `"review": { "decision": "ok" | "no" | "re" | "", "note": "…", "savedPath": "…", "at": "ISO 时间" }`，文件顶层多出 `reviewedAt`。只会写 `type` 为 `fenjingtai-candidates` 的 `.json` 文件。

## 1.6 自定义类型 · 口播音频 · 连播预览（合并 1.5）

- **界面**：工具条精简（章节目录变成图标开关；「修复分句」只在发现孤立标点时出现；交稿检查并进导出菜单；「视频审核」有候选时才出现）；画面面板输入即保存，去掉重复的保存按钮；选中态改成中性色，不再和 A roll 的蓝色混在一起；不进多选模式也能悬停勾选；快捷键面板 ⌘/；主题可以跟随系统（视图 菜单）；删除的项目进「最近删除」，30 天内能找回；自动备份可以只取回其中一个项目，不用整库替换。
- **修复**：「编辑链接或文件路径」打字时每个字都建一条素材的问题（旧数据里的残留会自动清掉）；表格备注 Shift+Enter 的换行被吞掉；项目名带 / 或 : 时导出文件名出错；CSV「共用画面」列是乱码编号、以 = 开头的内容会被 Excel 当公式；备份菜单写的保留份数和实际不符。
- **性能**：存盘只发改动过的项目（不再每次把整个库深拷贝、跨进程搬一遍）；按句查找改成索引；缩略图一律缩成小图再给界面；打字时侧栏、徽标的刷新合并成停手后一次。

## 1.9 视频审核改成「收件箱」

候选一多（一次找几十上百个画面）时，原来的长列表滚不到头、也不知道审到哪了；「已通过」页只增不减，和表格里的画面是重复的。现在：

- **审完就走**：窗口里只留待审的候选。审过的（通过 / 不要 / 换一个）先在原处展开着（来得及写意见、撤回），换到别的画面后收成一行，一行里能看到结果和意见，点「撤回」回到待审。
  - 去掉「待审 / 已通过 / 全部」三个页签。通过的结果就在表格的画面上看，顶部「已通过 N 个 · 在表格里看」点一下跳过去。
  - 审核与表格是同级页面，共用顶栏；用顶栏标签或 ⌘T 切换，Esc 不关闭审核页。审核页可以直接拖入候选 JSON，搜索句子会切到表格显示结果。
  - 「不要」的候选**离开审核页时自动清掉**（结果已经写回清单，Claude 读得到）；同一份清单再导入时，清单里已经标成「不要」的也不会再回来。去掉「清除『不要』的」按钮。
- **批次**：每次导入一份候选清单算一批。顶部下拉选批次（「第 3 批 · 冰冻胰腺这一章 · 10月5日 13:21 · 42 待审」），默认是最新一批，旁边写「还剩 N 个待审 / 共 M 个」，审完写「这一批审完了」。1.8 以前导入的候选归在「之前导入的」。
  - 批次名：清单顶层写了 `"batch": "冰冻胰腺这一章"` 就用它；没写就用这批涉及的章节名（多章写「X 等 N 章」），再不行用文件名。
  - 同一份清单再导入时，新加的候选、链接或时间改了重新回到待审的候选，算进新的一批。
- **左边画面目录，右边一次只看一个画面**：左边按章节列出这一批涉及的画面，每个写着「2 待审」「✓ 已通过」「等新候选」（只有换一个）或「已审完」；点哪个右边就显示哪个画面的口播原文和候选。
- **截图只截右边正在看的**：换画面时，没轮到的截图任务直接取消，几百个候选也不会一打开就去网上抓上千张图。
- **键盘快审**：`1` 通过 · `2` 不要 · `3` 换一个（作用于蓝框选中的候选）· `↑ ↓` 换候选 · `← →` 换画面 · `空格` 播放 / 暂停这段。一个画面里的候选都审完，稍等一下自动跳到下一个还有待审的画面；在意见框里打字时这些键不起作用，回车或 Esc 离开意见框。
- 右侧面板「视频候选 N 个 · 去审核」打开时，直接选中这个画面所在的那一批和这个画面。

## 1.9.1 片段命名与定位

- 新保存的视频片段和下载的原片，文件名开头会写对应句号，例如 `第125-127句_标题_1m41s-1m50s.mp4`。

## 1.10 可靠性与交互

详细改动见 `UPDATE-NOTES.md` 的「1.10.0」一节。要点：

- **项目 JSON 带上全部数据**：视频候选（审核结果、意见、批次、已保存片段）和片段保存位置都导出、导回；句子 id 保留，手动画面秒数不再失效。格式 v4。
- **视频审核更稳**：截取期间切项目，结果写回原项目；清单写不进去时不清掉「不要」的候选，并提示重试；撤销 / 重做后清单跟着改；候选换了链接或片段会撤下旧视频、回到待审。
- **交稿检查两种目标**：默认只查分镜方案；勾选「也检查素材交付」再查没关联素材、文件失联的镜头。
- **交互**：危险确认框回车不执行；弹窗焦点管理与 Tab 循环；菜单可用方向键；提示条分完成 / 提示 / 注意 / 出错；操作条上的类型按钮可以鼠标批量标注；「删除这句」收进「···」；紧凑行距（⇧⌘D）；面板「定位到正文」。
- **主进程**：坏掉的单个项目不影响其他项目打开；备份失败会重试并提示；同名片段并发保存不冲突；ffmpeg 协议白名单；下载原片可取消、有超时；IPC 只接受应用自己的页面。

### 候选清单格式补充（1.10）

- 同一份清单再导入时，候选的 `url` / `in` / `out` 任一项变了，就当作新版本：回到待审，旧的通过结果和已保存状态作废。只改 `title` / `why` / `license` 等说明文字不影响审核结果。
- 写回失败（文件只读、被移走）时，审核结果仍保存在项目里，下次审核或点「重试」时再写。

### 应用内更新与发布约定（1.10 起）

分镜台 1.10 起会自己检查更新：顶栏出现蓝色下载图标「更新」按钮时点开 → 下载并更新 → 重启并更新，换好后自动重新打开，项目数据不受影响。还在用 1.9.x 的同事需要最后手动下载安装一次 1.10，之后就能在软件里直接更新。

发布新版本时，为了让软件内更新能找到并校验更新包，请保持下面几点：

- 先把 `package.json` 的 `version` 改成新版本号，再打包；GitHub Release 的 tag 写成 `v` + 同一个版本号（如 `v1.10.1`）。软件会核对更新包里的版本号和 tag 是否一致。
- Release 里要有 `FenJingTai-mac-arm64.zip` 和 `FenJingTai-mac-x64.zip`（`npm run package` 产出的就是这两个名字；dmg 照常上传给第一次安装的人用）。软件内更新只用 zip。
- Release 的正文就是软件里显示的「更新说明」，可以直接贴 `UPDATE-NOTES.md` 里对应的一节。
- 不要标成 Pre-release 或草稿，否则软件不会提示更新。
- GitHub 会给每个上传的文件自动登记 SHA-256，软件下载后会核对，不需要另外上传校验文件。
